# DAFNI
Repository for my DAFNI report on FFA localisation

Strict Dissociation or Distributed Representation? A Single-Subject fMRI Analysis of Face and Object Perception

This project involves the localisation of the FFA (and LOC) from fMRI data analysis. It specifically explores the distributed versus modularity debate for visual processing to understand how the brain processes category specific information.

Tools used: Matlab, SPM12, MRIcroGL
